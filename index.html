SSTIeye

In progress
Server-side template injection scanner. Python.

Sends randomized arithmetic probes and confirms each against a baseline response, so real template evaluation is separated from plain reflection. Reads raw HTTP request files to reach authenticated endpoints, and tests both headers and parameters.

Why randomized probes

A fixed payload such as {{7*7}} can be blocked by a signature or appear in a page by coincidence. A random expression with a random expected result only passes when the server actually evaluated it.

Algorithms

TSP heuristics, a systematic empirical study

Benchmarked 20+ construction, local-search, and metaheuristic methods for the Euclidean TSP, including four original construction rules, under a significance-tested protocol with paired t-tests. Farthest Insertion was dominant among construction rules and a Lin–Kernighan-style local search dominant overall; a 12-stage metaheuristic hybrid improved on it by under 0.5%.

Shows experimental design, significance testing, and the discipline to report a negative result.

Algorithms

LKH candidate generation, independent verification

Investigated the candidate-generation stage of the Lin–Kernighan–Helsgaun heuristic. A purely topological candidate set (MST ∪ Delaunay ∪ k-NN) matched α-nearness candidate quality at roughly 20× the speed. A literature review then showed each result to be a known property of LKH, so the work is presented as verification, not as a new claim.

Shows profiling a state-of-the-art algorithm and honesty about what is actually new.

Machine learning

Riemann zeta zeros, machine-learning analysis

Applied an autoencoder-based unsupervised approach to the non-trivial zeros of the Riemann zeta function, using Odlyzko's dataset to look for structural patterns.

Shows unsupervised learning applied to a genuinely hard mathematical object.
